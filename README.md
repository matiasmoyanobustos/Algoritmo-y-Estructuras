# Estructura de Datos y Algoritmos

Repositorio para organizar las guías de la cursada de Algoritmos y Estructuras de Datos.

## Guías

- [Análisis de algoritmos](guias/analisis-de-algoritmos/README.md): diez ejercicios sobre vectores, matrices y Bubble Sort.

## Agregar una guía

Crear una carpeta independiente dentro de `guias/`, con un nombre breve en minúsculas separado por guiones. Cada guía puede incluir su propia especificación, prompts y código fuente. Luego, agregar aquí un enlace y una breve descripción.
